## How it works

`main.py` (Python 3, standard library only) draws the whole page procedurally — a hand-built 5x7 bitmap font, a dotted world map from hand-placed land ellipses, and a small PNG encoder — and writes it to `/output/entry.png` (`$MAKEFUN_OUTPUT_DIR` outside the grader). No network, no external assets, no timestamps: running it twice writes byte-identical output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Output: a 1024x1024 PNG.
